# Financial Time Series Prediction

Projekt koncentruje się na implementacji i porównaniu architektur uczenia maszynowego w zadaniu predykcji ceny zamknięcia akcji Apple Inc. (AAPL).

## Struktura repozytorium
- `src/` - generyczne klasy implementacyjne
- `notebooks/` - główne analizy i eksploracja danych  
- `models/` - zserializowane modele
- `first-src/` - archiwum z pierwszego tygodnia pracy nad projektem
- `utils/` - skrypty pomocnicze i backupy

## Zarządzanie zależnościami

```bash
uv venv
source .venv/bin/activate
uv sync
```
